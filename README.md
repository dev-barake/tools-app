# tools_app

Implementation roadmap
We'll implement the PDF Merger in these stages:

1 File selection: Open the device file picker and select multiple PDFs.
2 File listing: Display selected PDFs with filenames, sizes and page counts where available.
3 File management: Remove files and rearrange their merging order.
4 PDF validation: Check file extensions, readability, encryption and other potential issues.
5 PDF merging: Combine the selected documents into one PDF.
6 Output management: Choose the filename and save the resulting document.
7 Preview and sharing: Open, preview and share the merged PDF.
8 Testing: Test different document sizes, invalid files and failure scenarios.
